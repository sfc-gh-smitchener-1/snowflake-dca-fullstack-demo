- Replace `get_path()` with SQL recursive CTE BFS:
  ```sql
  WITH RECURSIVE bfs(node_id, depth, path) AS (
    SELECT target_node_id, 1, ARRAY_CONSTRUCT(source_node_id, target_node_id)
    FROM ONTOLOGY_GRAPH_EDGES WHERE source_node_id = :from_id
    UNION ALL
    SELECT e.target_node_id, b.depth + 1, ARRAY_APPEND(b.path, e.target_node_id)
    FROM bfs b JOIN ONTOLOGY_GRAPH_EDGES e ON e.source_node_id = b.node_id
    WHERE depth < 10 AND NOT ARRAY_CONTAINS(e.target_node_id::VARIANT, b.path)
  )
  SELECT * FROM bfs WHERE node_id = :to_id ORDER BY depth LIMIT 1
  ```
- Keep all other methods unchanged (already pure Snowpark SQL)
